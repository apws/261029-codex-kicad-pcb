A reusable local workflow for our 7xsys, 7xmod and 7xmem boards, with Codex as the only AI agent and JLCPCB as the preferred manufacturer. No family-specific electrical or mechanical requirements are assumed. This is a toolkit and experiment template; automatic placement and routing quality must be measured on our designs.

== Original project and our study

This local repository is an English, Codex-only adaptation of https://github.com/John-owo/pcb-agent-workflow[John-owo/pcb-agent-workflow]. Read its https://github.com/John-owo/pcb-agent-workflow/blob/main/README.md[original Traditional Chinese README] or https://github.com/John-owo/pcb-agent-workflow/blob/main/README.en.md[English overview]. The imported local source is link:../@extern/261029-pcb-agent-workflow/README.md[the external checkout].

Our aim is to understand the complete user/agent/skills/tools process and evaluate useful automation for 7xsys/7xmod/7xmem boards. Upstream also covers optional PCB fabrication and assembly through JLCPCB; those procedures remain useful with manual PCB design. Freerouting is our added experiment path, with no recorded real routing trial yet. See link:docs/261103-01-project-context-and-upstream.adoc[our motivation and scope] and link:docs/261103-02-CHAT-project-conversation.adoc[the project conversation].

== Quick commands

Run at this repository root. Linux KiCad Python is normally `/usr/bin/python3`.

[source,bash]
----
/usr/bin/python3 tools/pcb-lab.py doctor
/usr/bin/python3 tools/pcb-lab.py init --source /path/to/design-directory --dest experiments/board-a
/usr/bin/python3 tools/pcb-lab.py check --board experiments/board-a/design/Board.kicad_pcb --out experiments/board-a/reports/baseline
----

The source directory must contain the complete design and its local libraries. Replace `Board` with the actual filename. Read the experiment guide before routing. No router, MCP server or global Codex configuration is installed automatically.

Adapted from John-owo/pcb-agent-workflow at commit `8f14d7f9f76a19c7224bc7e5a325ef35e6fce06a`, imported 2026-10-29. The original remains in the adjacent external source directory. This adaptation keeps the original helper code unless explicitly documented; human documentation is translated and adapted for Codex/Linux.

Codex chooses actions and interprets results. KiCad stores and checks the design. Freerouting, when used, computes routes. Skills describe procedures; installing a skill does not install its external tools.
