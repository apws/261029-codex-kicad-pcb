== Local laboratory harness

`tools/pcb-lab.py` is our addition. `doctor` reports tool availability; `init` copies/records a project; `check` collects native ERC/DRC/parity, netlist/PDF and geometry; `export-dsn` writes native router input; `import-ses` imports into a new complete project; `compare` compares recorded geometry fields. It does not install software, launch routers, edit arbitrary schematics, control GUI or approve a design. Use its `--help` and each subcommand's help.

== What is not installed by this clone

Konnect, Freerouting, kicad-happy, CadQuery and pinned CAM packages are separate dependencies. Tool/skill existence in this directory does not imply availability or verified results. Start with installed native KiCad checks; add only what an experiment needs. A browser/mail connector matters for supplier interaction, not local routing.

== Tests and provenance

`tests/` contains retained upstream helper tests, adapted repository checks and our harness checks. Run relevant suites after changes; dependency-based skips are recorded as skips. `provenance/upstream-files.json` identifies the input snapshot and `document-map.json` explains the documentation migration. The original example's machine/manufacturing artifacts remain unchanged; translated explanations live in guides.
