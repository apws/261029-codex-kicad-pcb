Converted from upstream `docs/agents/triage-labels.md`. Optional historical integration for mattpocock engineering skills. These are not installed or required. The public adaptation is apws/261029-codex-kicad-pcb; these historical conventions do not authorize creating issues in the original upstream repository. Our glossary is guides/glossary.adoc and our decisions use dated docs/. Use --body-file for multiline GitHub text if publication is authorized.

The skills speak in terms of five canonical triage roles. This file maps
those roles to the actual label strings used in this repo's issue
tracker.

[cols=",,",options="header",]
|===
|Label in mattpocock/skills |Label in our tracker |Meaning
|`needs-triage` |`needs-triage` |Maintainer needs to evaluate this issue

|`needs-info` |`needs-info` |Waiting on reporter for more information

|`ready-for-agent` |`ready-for-agent` |Fully specified, ready for an AFK
agent

|`ready-for-human` |`ready-for-human` |Requires human implementation

|`wontfix` |`wontfix` |Will not be actioned
|===

When a skill mentions a role (e.g. "apply the AFK-ready triage label"),
use the corresponding label string from this table.

Edit the right-hand column to match whatever vocabulary you actually
use.
