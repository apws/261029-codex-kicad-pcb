Original language entry point: https://github.com/John-owo/pcb-agent-workflow/blob/main/README.md[Traditional Chinese README]; companion https://github.com/John-owo/pcb-agent-workflow/blob/main/README.en.md[English overview]. `upstream-files.json` contains source member SHA-256 values. `document-map.json` maps all upstream Markdown files to translated/adapted destinations or explicitly omitted Claude entry points. Human prose is English AsciiDoc. Most translations reorganize/consolidate repeated explanations and replace operational Claude instructions with Codex equivalents; they are maintained adaptations rather than line-for-line transcripts. Historical environment, prices and validation limits remain labeled.

Native example design/library/manufacturing/STEP/image/JSON artifacts are preserved byte-for-byte. Explanatory Markdown is moved to guides, so the example directory as a whole is not an identical original ZIP. For a byte-identical original repository, use the source commit. Machine-file hashes are verified during bootstrap; private experiments do not modify them.

LICENSE and NOTICE retain upstream and third-party attribution. NOTICE's original source-document paths identify upstream locations; use document-map.json for new guide destinations. Claude marketplace/hooks and their dedicated tests are omitted. Repository lint now validates English skills/AsciiDoc and local discovery links; privacy scanning handles those symlinks. No external model, router or MCP server is bundled.

`experiments/`, tool binaries, private order data and generated reports are ignored. Each real board experiment may have its own Git history. Do not publish confidential designs with the toolkit.
